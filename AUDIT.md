Дата: **31 октября 2026 года**. Игра «По следам великих открытий», автор — Чернеева Т. А.

## Статус

Игра **опубликована и проверена через HTTPS 31 октября 2026 года**:

- Игра: [https://acherneev-netizen.github.io/lomonosov-game/](https://acherneev-netizen.github.io/lomonosov-game/).
- Репозиторий: [acherneev-netizen/lomonosov-game](https://github.com/acherneev-netizen/lomonosov-game).

Владелец разрешил публичную публикацию и отдельно подтвердил право распространять три портрета и встроенные записи Microsoft Irina.

Использован действительный аккаунт `acherneev-netizen`. Создан публичный репозиторий `lomonosov-game`, исходники загружены в `main`, GitHub Pages настроен на GitHub Actions, включён HTTPS и переменная `PUBLICATION_APPROVED=true`. Пароли и токены в проект не добавлялись.

## Исходник и целостность

Источник истины — предоставленный `Ломоносов-игра.zip`, 5 127 197 байт. SHA-256:

```text
49707518c203b59cc30cb957c6ef0d54ee717f80b1a0377bd269613aa69d7a6e
```

Архив распакован в отдельный каталог `lomonosov-game-source` рядом с подготовленным проектом. Оригинальный архив не изменялся. Совпадение контрольных сумм из `CHECKSUMS.sha256` подтверждено для всех четырёх указанных файлов: игры, памятки и двух авторских уведомлений. Материалы для замены озвучки и исходный Windows-лаунчер сохранены в распакованном источнике; в публичный сайт они не включаются, так как игра в них не нуждается.

`COPYRIGHT.txt` и `THIRD_PARTY_NOTICES.txt` в проекте побайтно совпадают с оригиналами. Проверяющий скрипт фиксирует их SHA-256 и запрещает незаметную замену.

## Внесённые изменения

1. `ИГРА.html` перенесён в `index.html`. Новая игра не создавалась; игровая логика и содержимое заданий сохранены.
2. Написание имени в интерфейсе и метаданных приведено к требуемому `Чернеева Т. А.`. Сохранены постоянное уведомление, авторские метаданные, подпись в нижней части и авторство на дипломе. Оригинальные текстовые уведомления не редактировались.
3. На экранах до 420 пикселей панель управления переносится на вторую строку. Это устраняет найденную горизонтальную прокрутку на ширине 320 пикселей. Размер игровых кнопок не уменьшен.
4. На узких экранах скорректированы боковые отступы станций карты, чтобы карточки не перекрывались.
5. Памятка помещена в `docs/index.html`, её инструкции обновлены для открытия сайта; добавлены ссылки из игры к памятке и обратно.
6. Добавлены `.nojekyll`, русский `README.md`, воспроизводимые проверки и workflow GitHub Actions. Сайт отделён от инструментов проверки каталогом `_site/`, который формируется по явному списку файлов.
7. Добавлен предохранитель первой публикации: `PUBLICATION_APPROVED=true` требуется для задания размещения. Само создание публичного репозитория также требует разрешения владельца; эта переменная не ограничивает видимость репозитория.
8. Добавлена встроенная SVG-иконка вкладки с символом звезды, чтобы браузер не запрашивал отсутствующий `favicon.ico`.
9. Устранено зависание запуска при недоступной аудиосистеме: ожидание `AudioContext.resume()` ограничено 1,5 секундами. При нормальной работе звук включается сразу после действия пользователя; недоступный звуковой выход не блокирует игру. Добавлена отдельная проверка этого случая.
10. `.gitattributes` сохраняет точные байты HTML и оригинальных уведомлений при работе Git в Windows и Linux. Облачные тесты используют Ubuntu 24.04 и выделенный аудиоканал PulseAudio.

Все 119 исходных медиаобъектов проверены по содержимому и порядку; ни один не заменён и не перекодирован. Запуск звука после действия пользователя, приглушение музыки во время речи, отмена предыдущей записи, регулировка громкости и остановка при уходе со вкладки уже были предусмотрены оригиналом и сохранены.

## Производительность

Итоговый `index.html`: около **8,76 МБ**. Встроенные исходные бинарные медиа: 6 339 496 байт. Среди 119 исходных base64 data URL дублирующихся бинарных объектов не найдено. Base64 увеличивает объём; тестовое gzip-сжатие даёт примерно 5,07 МБ. Фактическое HTTP-сжатие зависит от хостинга и ещё не проверено на публичном сайте.

Вариант вынесения медиа исследован: он позволил бы загружать озвучку по мере прохождения и сократил бы начальный HTML приблизительно до 0,31 МБ. Однако исходная игра умеет скачивать автономную копию с новой озвучкой путём сериализации текущего HTML. Простая замена data URL внешними файлами сломала бы переносимость этой функции. Для текущей подготовки выбран прямо предусмотренный ТЗ путь: сохранить автономный HTML без ненужной переработки. Качество изображений и звука не снижалось. Дальнейшая оптимизация возможна отдельным изменением вместе с переделкой и проверкой экспортёра.

Измерения финального прогона на локальном HTTP-сервере Windows, без ограничения скорости:

| Chrome 156.0.8078.73 | 192 мс | 319 мс |

Вторая метрика включает ожидание загрузки страницы и поиска видимой кнопки Playwright. Эти значения описывают только локальный компьютер. Функциональная проверка опубликованной игры через интернет выполнена успешно; отдельные показатели скорости для реальных мобильных устройств не измерялись. При первой сетевой загрузке потребовалось увеличить таймаут браузера до минуты: автономный HTML содержит все записи, поэтому скорость зависит от соединения.

## Проверки

Использован Playwright **1.62.1**. `npm ci --ignore-scripts` успешно установил зафиксированные зависимости, npm сообщил об отсутствии известных уязвимостей в проверенном наборе на момент запуска. Синтаксис встроенного JavaScript проверен `node --check`; HTML, ссылки, авторство, уведомления и неизменность медиа — `scripts/verify.py`. Формирование `_site/` выполнено успешно. Локальный HTTP-просмотр вернул статус 200.

Финальный браузерный прогон: **43 успешные группы проверок, 1 явно пропущенная звуковая проверка WebKit для Windows, ошибок выполнения сценария нет**. JSON и снимки экрана находятся в локальном `test-results/`; этот каталог не публикуется и не включается в исходный ZIP поставки. После запуска проверок владельцем он будет создан заново. В GitHub Actions результаты сохраняются как диагностический artifact.

После исправления ожидания звукового устройства выполнен полный облачный прогон на Ubuntu 24.04: **48 успешных групп проверок, без пропусков и ошибок**. Движки: Chromium 151.0.7922.34, Firefox 153.0 и WebKit 26.5. В облаке подтверждены музыка, эффекты, голос и отсутствие наложения записей во всех трёх движках, а также запуск при зависшем `AudioContext.resume()`.

Опубликованный сайт дополнительно проверен независимым сценарием `scripts/check-live.cjs` в Chrome на ширинах 1366 и 390 пикселей. Главная игра, памятка и оба авторских уведомления вернули HTTP 200 через действительный HTTPS; содержимое каждого файла совпало с локальным по SHA-256. Проверены изображения, начало путешествия, воспроизведение голоса после нажатия, выполнение задания, сохранение после обновления, переход к памятке и обратно. Ошибок JavaScript, неудачных запросов и HTTP-ресурсов внутри HTTPS-страницы не обнаружено. Результат сохраняется в `test-results/live-results.json`.

## Авторские уведомления и условия перед публикацией

Авторская подпись сохранена везде, где присутствовала, и постоянно видна в интерфейсе. Новая лицензия на игру не добавлялась. Присутствующие в оригинале MIT-уведомления React, React DOM и scheduler сохранены.

Исходное уведомление сообщает, что портреты предоставлены пользователем и записи синтезированы голосом Microsoft Irina. В самом архиве подтверждающих документов нет. 31 октября 2026 года владелец отдельно ответил: «Да, права на портреты и озвучку подтверждаю». Публикация производится на основании этого подтверждения; техническая подготовка не является самостоятельной юридической экспертизой.

В `COPYRIGHT.txt` есть ссылка текстом на `docs/HISTORICAL_SOURCES.md`, но такого файла в исходном архиве нет. Оригинальное уведомление сохранено без изменения. Отсутствующий документ не используется игрой и не мешает запуску; при наличии его можно добавить владельцу. Историческое содержание заданий при подготовке не переписывалось и не проходило отдельную научную экспертизу.

## Дальнейшее сопровождение

1. Для обновления вносить проверенные изменения в `main`; GitHub Actions автоматически выполняет проверки и размещение. При ошибке предыдущая опубликованная версия сохраняется.
2. После обновления дождаться зелёных `check` и `deploy`, затем выполнить `npm run check:live -- https://acherneev-netizen.github.io/lomonosov-game/`.
3. Сохранять исходный архив и резервные копии репозитория. Использовать обратный коммит или Revert pull request для отката.
4. Остаётся аппаратная проверка на реальной интерактивной доске, Android-планшете и iPad. Эмуляция размеров, касаний и WebKit не заменяет проверку этих устройств.

Порядок обновления, резервного копирования, отката и переноса на другой статический хостинг подробно описан в [README.md](README.md).
